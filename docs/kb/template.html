What Artha knows, person by person

Each person has their own context space on the live system: who's who in their life, what they call each person, facts Artha learned, their khata and plans, and habits from what they confirmed. Numbers below come from a live test run against the deployed site.

How a context space is stored

  • One SQLite file per person, kept in S3 (about 160 KB each). Isolation is by design: deleting a person's data is deleting one file.
  • Layers: people and what the user calls them, facts, conversation turns with each action's status, chats and calls, calendar, khata, and habits learned only from what the user confirmed.
  • Every piece of text gets a 256-number vector (text-embedding-3-large, stored as 8-bit), so a Marathi question can find an English note by meaning.
  • Kept for 90 days. Facts that keep being used stay alive; khata entries roll into a carried-forward balance before they expire.
